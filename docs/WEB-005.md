## Ejecución reproducible

Requisitos de construcción: Node 24.19.0, npm 11.9.0, Python 3. Instalación `npm ci`. Preparar archivos autorizados fuera de Git y ejecutar:

```sh
python3 tools/web-005/import-corpus.py \
  --corpus /ruta/entrega-integral.zip \
  --index /ruta/INDICE_EDITORIAL_308.json \
  --static /ruta/paquete-web-estatico.zip \
  --evidence /ruta/matriz-tecnica.csv \
  --illustrations /ruta/manifiesto-ilustraciones.csv \
  --output private/web005
WEB005_PRIVATE=1 npm run build
python3 tools/web-005/verify-build.py private/web005/dist
WEB005_PRIVATE=1 npm run preview -- --ignore-lock --port 4322
```

PowerShell: definir `$env:WEB005_PRIVATE='1'` antes de los comandos npm; `Remove-Item Env:WEB005_PRIVATE` para volver al modo DEMO. El SHA esperado del ZIP integral se fija desde el checksum independiente suministrado en Drive (v4); no se deriva del archivo de entrada para autoautorizarlo. El importador rechaza destinos existentes; usar una carpeta nueva si se repite una importación y conservar el origen. Los resultados privados y capturas deben permanecer fuera de Git y de artefactos públicos de Actions. La CI pública prueba el modo DEMO y casos sintéticos del adaptador/servidor; no dispone del corpus.

Paquete Windows independiente, con Node portable win-x64 24.19.0: verificar ZIP con SHASUMS256 oficial, formato PE AMD64 y licencia; conservar hashes dentro del paquete. `ABRIR_REVISION.cmd` usa exclusivamente ese runtime, servidor HTTP solo 127.0.0.1 con puerto dinámico, integridad al inicio, Host restringido, rutas permitidas, CSP, ausencia de escritura HTTP y cierre autenticado. `CERRAR_REVISION.cmd` detiene solo esta sesión. No se necesita npm para revisar. Runtime Windows no ejecutado en Linux; prueba física pendiente.

`ABRIR_MOVIL_TABLET.html` es una variante autónoma de las mismas páginas Astro, con CSS, índice y originales embebidos; navegación hash, búsqueda, controles de lectura y exportación local sin servidor. No es un nuevo corpus ni una reconstrucción de textos. Los navegadores/vistas previas móviles pueden restringir HTML local/descargas: probar con un navegador que permita ejecución de HTML local. El servidor Windows se mantiene en loopback y no se abre a la LAN para eludir esta limitación. La prueba automática carga esos bytes en Chromium sin conexión; la apertura `file://` del navegador gestionado fue bloqueada por política del entorno y no se declara superada.

## Privacidad, limitaciones y rollback

Sin cuentas, cookies, analítica, telemetría, servidor remoto ni recursos remotos automáticos. Solo se descargan fuentes si el lector pulsa sus enlaces. JSON/TXT de evaluación local, nunca envío automático. La hoja comienza en “No probado” y `automaticApproval:false`. No hay persistencia automática de comentarios; exportar antes de cerrar.

Búsqueda de texto completo conserva un índice en memoria; no se vende como rendimiento real en PC/móvil. La paginación limita DOM, no el tamaño del corpus descargado. Sin calculadoras, mapa georreferenciado, ilustraciones terminadas ni certificación técnica. Navegación/búsqueda del HTML autónomo tiene un controlador offline específico, probado por separado. No se declara aprobación WCAG ni Windows por resultados axe.

Rollback antes de integrar: cerrar revisión, conservar originales/ZIP, volver al checkout base `5a06e69` o compilar sin `WEB005_PRIVATE`; el sitio DEMO previo es el valor por defecto. No hay migración, servicio remoto o DNS que revertir. Si se autorizase una integración futura, revertir los commits de esta rama mediante otro PR; nunca force-push. PR anteriores permanecen abiertos e intactos. WEB-004 no se reemplaza ni reempaqueta.
